Hands-on with Project Management Tools: Practice project tracking, task assignment, and progress monitoring using Trello and JIRA on a simulated project.

% ═══════════════════════════════════════════════════════════
\section{Introduction}
% ═══════════════════════════════════════════════════════════
Modern software development requires robust tools to manage complexities, coordinate team members, and ensure timely delivery. Agile project management relies heavily on tracking systems to maintain visibility over tasks, bugs, and sprints.

In this assignment, we demonstrate task assignment and progress monitoring for the \textbf{CA Firm Attendance and Article Management System}. Because this project involves complex dual-verification logic (Face Recognition + GPS) and distinct user portals (Admin vs. Article Trainee), we simulate the development lifecycle using two industry-standard tools:
\begin{enumerate}
    \item \textbf{JIRA (Scrum Approach):} Used for managing the core backend structure, database, and biometric API integrations within 2-week Sprints.
    \item \textbf{Trello (Kanban Approach):} Used for managing the React.js UI components and maintaining a continuous flow of front-end deliverables.
\end{enumerate}

\section{Trello Implementation (Kanban Framework)}
% ═══════════════════════════════════════════════════════════
Trello is utilized for the frontend React.js development of the Admin and Article Dashboards.

\subsection{Board Layout (Lists)}
Our Trello board represents a continuous delivery pipeline:
\begin{enumerate}
    \item \textbf{Backlog:} All planned UI views (e.g., Leave Application Form).
    \item \textbf{Up Next:} Priority components to be coded this week.
    \item \textbf{In Development:} Components currently being coded.
    \item \textbf{Testing/Staging:} Components under peer review.
    \item \textbf{Done:} Successfully merged code.
\end{enumerate}

\subsection{Detailed Card Simulation}
Each Trello card represents a specific component containing checklists and tags.
