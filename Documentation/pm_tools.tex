\section{Problem Statement}
% ═══════════════════════════════════════════════════════════
Hands-on with Project Management Tools: Practice project tracking, task assignment, and progress monitoring using Trello and JIRA on a simulated project.

% ═══════════════════════════════════════════════════════════
\section{Introduction}
% ═══════════════════════════════════════════════════════════
Modern software development requires robust tools to manage complexities, coordinate team members, and ensure timely delivery. Agile project management relies heavily on tracking systems to maintain visibility over tasks, bugs, and sprints.

In this assignment, we demonstrate task assignment and progress monitoring for the \textbf{Traffic Prediction and Analysis System}. We simulate a development lifecycle using two industry-standard tools:
\begin{enumerate}
    \item \textbf{JIRA (Scrum Approach):} Used for managing structured two-week sprints, handling complex backend development, and tracking machine learning integrations.
    \item \textbf{Trello (Kanban Approach):} Used for visualizing and managing the daily workflow of UI components and frontend React.js development.
\end{enumerate}

% ═══════════════════════════════════════════════════════════
\section{JIRA Implementation (Scrum Framework)}
% ═══════════════════════════════════════════════════════════
Jira Software by Atlassian is utilized to manage the backend, database, and API integrations of the Traffic Prediction System. Our team employs a Scrum methodology with defined Epic structures and 2-week Sprint cycles.

\begin{itemize}
    \item \textbf{Project Name:} Traffic Prediction Backend (TPB)

        \item \textit{Epic 2:} MongoDB Schema Setup and Optimization

    \end{itemize}
\end{itemize}

\section{Trello Implementation (Kanban Framework)}
% ═══════════════════════════════════════════════════════════
Trello is utilized for the frontend UI/UX development (React.js) of the system. The Kanban board provides a highly visual, continuous flow model perfect for managing styling, responsive design tweaks, and frontend component creation.

\subsection{Board Layout (Lists)}
Our Trello board represents a continuous delivery pipeline:
\begin{enumerate}
    \item \textbf{Features Backlog:} All planned UI components (e.g., Map View, Leaderboard).
    \item \textbf{Up Next:} Priority components to be picked up this week.
    \item \textbf{In Progress (Doing):} Components actively being coded.
    \item \textbf{Testing/QA:} Components deployed to the staging environment for review.
    \item \textbf{Done:} Successfully merged and deployed to production.
\end{enumerate}

\section{Conclusion}
% ═══════════════════════════════════════════════════════════
Through this exercise, we successfully simulated task assignment and progress tracking for the \textbf{Traffic Prediction and Analysis System}. By leveraging \textbf{JIRA} for backend/integration Sprints and \textbf{Trello} for continuous frontend flow, the development process remains structured, transparent, and collaborative. JIRA provided the rigid estimation and story point tracking necessary for complex backend logic, while Trello offered the lightweight flexibility required for rapid UI prototyping.
